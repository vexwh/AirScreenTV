# Contributing

1. Fork the repository and create a feature branch.
2. Build and test:
   ```bash
   ./gradlew :app:assembleDebug :app:testDebugUnitTest
   ```
3. Keep changes focused and include tests for protocol/parser changes.
4. Do not commit keystores, local.properties, pairing keys, APKs, logs, or
   personal network details.
5. Open a pull request describing the change and how it was tested.

By contributing, you agree that your contributions are licensed under GPL-3.0.
